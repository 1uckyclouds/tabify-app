# 项目构建脚本

这个目录包含项目的构建和部署脚本。

## 脚本说明

### Chrome 扩展构建
- **位置**: `../apps/build-extension.js`
- **用途**: 构建 Chrome 扩展包
- **功能**:
  - 构建 Next.js 应用
  - 处理 Chrome 扩展兼容性
  - 提取内联脚本
  - 生成 CSP 安全策略
  - 复制扩展文件

## 使用方法

### 构建扩展
```bash
cd ../apps
node build-extension.js
```

### 开发模式
```bash
cd ../apps
npm run dev
```

### 生产构建
```bash
cd ../apps
npm run build
```

## 注意事项

1. 构建前确保清理旧的构建文件
2. 构建后检查语法校验报告
3. 测试扩展功能是否正常
4. 检查 CSP 策略是否符合要求
