# Tabify Chrome扩展

## 概述

Tabify是一个高效的Chrome浏览器标签页管理插件，帮助用户解决标签页过多导致的浏览器卡顿问题。通过一键收纳、智能分组、批量操作等功能，显著提升用户的浏览效率和体验。

## 功能特性

### 🚀 核心功能
- **一键收纳**：快速收纳当前窗口所有标签页，释放内存
- **智能分组**：AI驱动的自动分类，提高管理效率
- **批量操作**：支持批量恢复、删除、分组等操作
- **拖拽管理**：直观的拖拽界面，轻松调整标签页分组
- **实时搜索**：快速查找已收纳的标签页
- **数据导入导出**：支持JSON格式，兼容OneTab

### ⌨️ 快捷键
- `Ctrl+Shift+T` (Mac: `Cmd+Shift+T`): 一键收纳当前窗口所有标签页
- `Ctrl+Shift+M` (Mac: `Cmd+Shift+M`): 打开标签页管理界面

### 🎯 使用场景
- **重度浏览器用户**：经常同时打开大量标签页
- **知识工作者**：需要管理大量网页资源的研究人员、开发者、学生
- **效率追求者**：希望优化浏览器性能和工作流程
- **OneTab用户**：寻找更好的标签页管理替代方案

## 安装方法

### 开发者模式安装（当前版本）

1. **打开Chrome扩展管理页面**
   - 在Chrome地址栏输入：`chrome://extensions/`
   - 或者通过菜单：更多工具 → 扩展程序

2. **启用开发者模式**
   - 在扩展管理页面右上角，打开"开发者模式"开关

3. **加载扩展**
   - 点击"加载已解压的扩展程序"按钮
   - 选择本项目的 `extension` 文件夹
   - 点击"选择文件夹"

4. **确认安装**
   - 扩展安装成功后，会在工具栏显示Tabify图标
   - 首次使用时会请求必要的权限

### Chrome Web Store安装（即将推出）

扩展将在开发完成后提交到Chrome Web Store，届时可以直接在线安装。

## 使用指南

### 基本操作

1. **收纳标签页**
   - 点击工具栏的Tabify图标
   - 或使用快捷键 `Ctrl+Shift+T`
   - 当前窗口的所有标签页将被收纳并关闭

2. **管理标签页**
   - 点击Tabify图标后会自动打开管理界面
   - 或使用快捷键 `Ctrl+Shift+M` 直接打开
   - 在管理界面中可以查看、搜索、分组、恢复标签页

3. **恢复标签页**
   - 在管理界面中点击任意标签页项目
   - 标签页将在新窗口中重新打开
   - 支持批量选择和恢复

### 高级功能

1. **智能分组**
   - 选择未分组的标签页
   - 点击"智能分组"按钮
   - AI将根据内容相关性自动分类

2. **手动分组**
   - 选择要分组的标签页
   - 点击"添加到分组"按钮
   - 选择现有分组或创建新分组

3. **拖拽操作**
   - 直接拖拽标签页到不同分组
   - 拖拽调整分组内标签页顺序
   - 支持批量拖拽操作

4. **数据管理**
   - 通过菜单进行数据导入导出
   - 支持JSON格式和OneTab兼容格式
   - 自动本地备份，防止数据丢失

## 权限说明

扩展需要以下权限来正常工作：

- **tabs**: 读取和管理标签页信息
- **storage**: 本地存储标签页数据
- **activeTab**: 获取当前活动标签页
- **scripting**: 执行内容脚本
- **host_permissions**: 访问网页内容以获取favicon等信息

所有权限仅用于扩展功能实现，不会收集或上传用户数据。

## 技术架构

### 核心组件
- **Manifest V3**: 使用最新的Chrome扩展标准
- **Service Worker**: 后台脚本处理核心逻辑
- **React 19**: 现代化的用户界面
- **TypeScript**: 类型安全的代码开发
- **Tailwind CSS**: 响应式UI设计

## 开发说明

### 开发环境
- Node.js 22.17.1+
- Chrome 88+
- 支持Manifest V3的现代浏览器

### 调试方法
1. 在Chrome扩展管理页面找到Tabify扩展
2. 点击"详细信息"
3. 启用"收集错误"选项
4. 使用"检查视图"来调试不同组件：
   - 后台页面：调试background.js
   - 弹出窗口：调试popup.html
   - 管理界面：调试manager.html

### 更新扩展
1. 修改代码后，在扩展管理页面点击刷新按钮
2. 或者重新加载整个扩展
3. 某些更改可能需要重启Chrome

## 常见问题

### Q: 扩展无法正常工作？
A: 请检查：
- Chrome版本是否为88+
- 是否启用了开发者模式
- 扩展是否有必要的权限
- 控制台是否有错误信息

### Q: 标签页收纳后找不到？
A: 
- 点击扩展图标打开管理界面
- 使用搜索功能查找特定标签页
- 检查是否在某个分组中

### Q: 如何备份数据？
A:
- 在管理界面点击菜单 → 导出
- 数据将以JSON格式下载
- 可以通过导入功能恢复数据

### Q: 支持同步到其他设备吗？
A: 当前版本使用本地存储，不支持跨设备同步。未来版本将考虑添加云同步功能。
